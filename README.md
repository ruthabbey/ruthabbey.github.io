# Ruth Abbey Portfolio

Static multi-page portfolio for Ruth Naayi Odankey Abbey.

## Local preview

From the repository root, run the bundled Python executable with the module http.server on port 8000, then open http://localhost:8000/.

## Pages

- index.html - About and selected work
- publications.html - Research and publications
- news.html - Verified updates
- education.html - Education history
- honours.html - Awards and scholarships

The site intentionally has no gallery section. Contact details are limited to the public-safe information selected for this portfolio.
